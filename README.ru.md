# nuckty-ext-command-deploy-ftp

> **Публикация собранного артефакта по FTP/FTPS — команда `deploy-ftp`.**

Командное расширение для [nuckty](https://github.com/nuckty/nuckty). Публикует каталог `outDir`, сверяясь с `manifest.json`: загружает новые и изменившиеся файлы и удаляет лишние файлы на сервере. Требуется FTP или FTPS; SSH, rsync и Git на сервере не нужны.

## Что добавляет

Одну команду CLI, регистрируемую через `env.commands`:

```
nuckty deploy-ftp [target] [--force] [--dry-run]
```

- `target` — выбирает таргет из `config/config-nuckty.ts`; без аргумента используется первый объявленный таргет, неизвестное имя отклоняется до подключения.
- `--force` — загружает все локальные файлы и обходит защиту от массового удаления; удаление устаревших файлов сохраняется.
- `--dry-run` — читает состояние сервера и показывает план, не меняя локальные и удалённые файлы.

## Как работает

1. Проверяет локальный манифест, относительные пути, принадлежность файлов артефакту, размеры и MD5 до подключения.
2. Читает каждый удалённый каталог; ошибка любого `LIST` останавливает публикацию.
3. Без `--force` скачивает манифест, если он присутствует в полном списке файлов; ошибка скачивания или неверный формат останавливает команду. Отсутствие определяется по списку, а не по коду ошибки FTP. `--force` пропускает скачивание и загружает все локальные файлы.
4. Вычисляет загрузки и удаления, проверяет порог массового удаления, создаёт каталоги и передаёт файлы. Ошибки загрузки останавливают команду до удаления файлов.
5. Удаляет устаревшие файлы, проверяет полный список и повторяет загрузку отсутствующих файлов или файлов неверного размера. Ошибки загрузки, удаления и проверки запрещают публикацию манифеста.
6. Загружает `manifest.json` последним; ошибка его передачи завершает команду с ошибкой. Публикация всего сайта не атомарна: уже переданные файлы остаются на сервере при последующем отказе.

### Защита от массового удаления

Если доля файлов к удалению превышает порог (по умолчанию 30%), команда останавливается и указывает на `--force` — чтобы уберечь от случайной очистки.

## Учётные данные

Учётные данные читаются из `config/auth-ftp.json` (исключите его из контроля версий) или `FTP_HOST`, `FTP_USER`, `FTP_PASSWORD`, `FTP_PATH`, необязательных `FTP_PORT` и `FTP_SECURE`. Полный набор переменных окружения имеет приоритет над файлом.

По умолчанию используется обычный пассивный FTP. JSON `secure: true` или `FTP_SECURE=true` включает explicit FTPS с проверкой сертификата и имени сервера. `false` выбирает обычный FTP; другие значения отклоняются. Ошибка TLS завершает подключение без перехода на обычный FTP. Для частного CA настройте доверенные сертификаты Node, сохранив проверку сертификата.

Ядро не зависит от `basic-ftp`; зависит расширение, и импорт ленивый — `register(env)` библиотеку не загружает.

## Как подключить

Пример продолжает быстрый старт со стандартным обработчиком `nuckty-ext-block-root`. Добавьте новое расширение в `ext` глобального `config/config-nuckty.ts`, сохранив остальные записи. Если обработчик документа собственный, оставьте его вместо `nuckty-ext-block-root`.

```ts
import { defineNucktyConfig } from 'nuckty';

export default defineNucktyConfig({
    targets: { main: { configDir: 'config/', outDir: 'site/' } },
    ext: ['nuckty-ext-block-root', 'nuckty-ext-command-deploy-ftp'],
});
```

## Контракт

`register(env: NucktyEnv)` регистрирует команду через `env.commands.add` и объявляет `force` и `dry-run` булевыми флагами.

## Спецификация

Поведение закреплено в спецификации openspec `ext-command-deploy-ftp` (`openspec/specs/ext-command-deploy-ftp/spec.md`): команда публикации, сравнение по манифесту и минимальные операции, защита от массового удаления, FTP в пассивном режиме; explicit FTPS включается отдельно.


Перед соединением команда сверяет размер и MD5 каждого локального файла с манифестом. Перед последней отправкой манифеста она повторяет проверку и отклоняет изменившийся артефакт. Проверка на сервере использует LIST и размер; независимого подтверждения удалённого хеша нет. Во время публикации артефакт менять нельзя.
